# バンドマンたける

2年半でメジャーデビューを目指す、ドット絵のバンド育成シミュレーションです。
ビルド不要の静的サイトで、`index.html` を開けばそのまま動きます。

## 遊び方

1行動＝1週間。全120週（2年半）で、練習・アルバイト・作曲・ライブを選びながらバンドを育てます。
知名度・フォロワー・総合力が条件を満たすとメジャーデビューのオファーが届きます。

- 練習に寄せるとステータスは伸びるが知名度が足りずインディーズ止まり
- ライブに寄せるとメジャーになれるがステータスは伸び悩む
- 身の丈に合わない会場を押さえると赤字のうえ評判も落ちる

## ローカルで動かす

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。
`file://` で直接開くとBGMやFirebaseが動かないため、簡易サーバー経由を推奨します。

## オンライン機能

ランキング・サクセス記録・所属バンド一覧にFirebase(Firestore)を使っています。
セットアップは [FIREBASE_SETUP.md](FIREBASE_SETUP.md) を参照してください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組みとCSS |
| `game.js` | ゲームロジック(行動・イベント・成長・デビュー条件) |
| `ui.js` | 画面描画と演出 |
| `stats-engine.js` | ステータス・経験点・特殊能力 |
| `keiba.js` | 競馬イベント |
| `sfx.js` | 効果音(WebAudioで合成) |
| `icons.js` | 画像アセット(base64) |
| `firebase-service.js` | Firestore連携 |
| `bgm/` | BGM |

## 開発用のプレビュー

- `index.html?event=1` … 選択肢イベントだけを個別に確認
- `index.html?ending=1` … エンディングだけを確認
